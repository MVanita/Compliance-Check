![License](https://img.shields.io/badge/license-MIT-green)  > Outil open-source d'auto-évaluation de maturité cyber-conformité > pour PME et startups. Score instantané, radar chart, plan de remédiation PDF.  ## 🎯 Pourquoi ce projet ?  Les PME n'ont pas toujours accès à un audit ISO 27001 complet. 
ComplianceCheck leur donne une première visibilité sur leur posture de conformité en 5 minutes, sans données collectées.  ## ✨ Fonctionnalités  
- 📋 **25 contrôles** couvrant ISO 27001 Annexe A + NIS2 Art.21/23 
- 🏢 **7 domaines** : Gouvernance, Accès, Cryptographie, Incidents,   Réseau, Continuité, Conformité réglementaire 
- 📊 **Score de maturité** : Initial / En développement /   Intermédiaire / Avancé - 🕸️ **Radar chart** interactif par domaine - 
📄 **Export PDF** du rapport de remédiation priorisé
- 🔒 **0 donnée collectée** — 100% client-side  ## 
🚀 Demo  👉 [Accéder à ComplianceCheck](https://mvanita.github.io/Compliance-Check/)
## 📚 Cadres de référence  | Framework | Couverture | |-----------|-----------| | ISO 27001:2022 | Annexe A (contrôles A.5 à A.8) | | NIS2 | Art. 21 (mesures) & Art. 23 (notification) | | RGPD | Obligations DPO, registre des traitements |  ## 🛠️ Stack technique  HTML5 · CSS3 · JavaScript vanilla · Chart.js · jsPDF  Aucune dépendance serveur — fonctionne entièrement dans le navigateur.  ##
